# Quantum Gravity Wrench (QGW)

**Author:** Jiang Congguo  
**Date:** 2026-04-11  

## What is this?

A constructive framework for quantum gravity,  
proving that spacetime emerges from $(\infty,4)$-categories  
via Gromov–Hausdorff compactness.

## Core Contributions

1. **GH-compactness in dimension 4**
2. **Discrete Wrench Action $S$**
3. **Formal verification via Coq**
